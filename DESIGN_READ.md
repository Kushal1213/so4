# Skill 3 — design-taste-frontend

## Design Read

Reading this as: redesign overhaul of a wellness AI SaaS landing for individuals and clinicians, with a calm dark-nature premium language, leaning toward Tailwind v3 + Syne/Outfit sans stack + Motion (not a dashboard redesign — product chrome inherits tokens only).

## Mode

**Redesign — Overhaul** (user: remap whole product). Preserve IA/routes. New visual language. Brand tokens from brandkit (seafoam accent, crescent mark).

## Dials

| Dial | Value | Why |
|------|-------|-----|
| DESIGN_VARIANCE | 7 | SaaS landing asymmetric, not artsy chaos |
| MOTION_INTENSITY | 6 | Motivated entry + scroll reveal; spring physics |
| VISUAL_DENSITY | 3 | Calm wellness / airy |

## System

Honest aesthetic: dark nature / calm premium. Not Fluent/Carbon. Stack stays React + Vite + Tailwind v3 + Phosphor + motion/react. Fonts self-hosted via `@fontsource` (no Google Fonts CDN).

## Serif discipline

Fraunces removed from product UI (banned LLM default). Display = **Syne**. Body = **Outfit**. Mono = **IBM Plex Mono**. Brand boards may keep serif specimens; live app does not.
