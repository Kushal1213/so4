# Sleep Oracle — Brand System

Generated and applied via **brandkit** skill.

## Strategy

| Lens | Decision |
|------|----------|
| Category | Sleep intelligence / wellness AI |
| Audience | Individuals, clinicians, organizations |
| Personality | Calm, trustworthy, precise, nocturnal |
| Emotional promise | Clarity after rest — understand tonight, improve tomorrow |
| Cultural position | Quiet premium health tech, not neon AI |
| Trust level | High — screening aid language, no hype |
| Visual world | Dark nature / calm system — mist, night, seafoam |
| Core metaphor | Moon aperture + oracle window (seeing clearly in the dark) |
| Avoid | Purple AI glow, rocket metaphors, medical alarm red as brand color |

## Logo

**Mark:** Crescent cut from a circle — negative-space “O” / oracle aperture.  
**Wordmark:** Fraunces (display), paired with Outfit for UI.  
**Construction:** Circle guide + offset crescent; seafoam fill on night ground.  
**Files:** `frontend/public/brand/mark.svg`, `frontend/public/favicon.svg`, `frontend/src/components/Brand.jsx`

## Typography

- **Display:** Syne (product UI) — brand name, page titles  
- **Sans:** Outfit — UI, body, navigation  
- **Mono:** IBM Plex Mono — scores, API paths, tabular data  
- Brand-kit boards may show a serif specimen; the live app uses sans display only (design-taste serif discipline).  

## Voice

- Tagline: **Clarity after dark.**  
- Supporting: Measure tonight. Improve tomorrow.  
- Sentence case. No “elevate / unleash / seamless.”  
- Screening aid only — not medical advice.
